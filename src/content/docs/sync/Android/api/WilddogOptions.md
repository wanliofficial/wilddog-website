### getSyncUrl()
##### 定义

```java
String getSyncUrl()
```

##### 说明

[WilddogSync](/sync/android/api/wilddogsync/) 的根路径 URL，例如： `http://example.wilddogio.com`。

##### 返回值

`String` WilddogSync 的根节点路径。
